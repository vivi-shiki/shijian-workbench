# 数据集第三阶段计划

## 目标

在已经冻结的“原图 + 双 OCR + 最终阅读结果”与自动连接之上，逐步形成可用于提示词改进、回归测试和模型评估的可信监督数据。第三阶段不直接把所有自动连接标为金标准，而是按证据强度分层。

## 三类金标准

1. **字词校勘金标准**：原图局部、两套 OCR 候选、最终采用文本、采用理由与错误类型。
2. **结构金标准**：标题、作者、组诗、正文、注文、跨页关系以及现代排版边界。
3. **任务决策金标准**：某次候选为何批准、驳回或要求重跑，包含提示词版本、模型、参数和检查结果。

## 实施顺序

1. 从 `links.json` 中优先抽取两套 OCR 一致且与最终文本完全匹配的连接，标为 `silver`，不得直接标为人工确认。
2. 将单源匹配、模糊匹配、未连接以及仍有 issue 的目标排入人工复核队列。
3. 人工在原图上确认后，追加独立 annotation 事件；事件只追加，不改写原始冻结快照。
4. 由 annotation 事件生成三种派生视图：提示词简例、回归测试夹具、评估样本。
5. 每个提示词或 skill 版本固定一组训练样本和一组从未提供给模型的保留评估集，避免“用答案教完再测答案”。
6. 每轮只改一个主要变量，记录提示词版本、模型版本、参数、输入页、输出、验证器结果和人工结论。

## 最小记录格式

每条 annotation 至少包含：`annotation_id`、`dataset_id`、`target_id`、`source_refs`、`decision`、`accepted_text`、`error_types`、`rationale`、`actor`、`created_at`。结构判断另含 `entry_kind`、`field` 和 `boundary`；执行判断另含 `prompt_version`、`skill_version`、`model`、`run_id`。

## 评估指标

- 字符准确率与标点准确率分开计算。
- 标题、正文、注文、作者、组诗、跨页等结构字段分别计算 precision、recall、F1。
- 统计无需人工改动、轻微改动、重做、无法判断四种页面结论。
- 单独统计高风险错误：漏文、串栏、正文注文混淆、标题正文混淆、跨页断裂、擅自补字。
- 最终以“每页人工修订字符数”“每页人工处理时间”“高风险错误率”作为工作流价值指标。

## 完成条件

先完成 1–42 页中全部自动未连接和模糊连接的复核；再按错误类型覆盖度选择代表性简例。用于提示词的简例应短小、互不重复并说明决策理由，保留评估集不得进入 AI 上下文。
